Privacy Policy – LumiTale Autopilot

Last updated: 17 November 2026

LumiTale Autopilot ("the app") is a private, internal tool operated by LumiTale Studio, the creator of the YouTube channel LumiTale Bedtime. The app is used only by the channel owner to upload and schedule the channel's own videos and to read the channel's own statistics. It is not offered to the public and has no other users.

Use of YouTube API Services

The app uses the YouTube API Services (YouTube Data API v3 and YouTube Analytics API). By using the app you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data the app accesses

  • Authorization token: an OAuth 2.0 token for the channel owner's own Google account, granted with the scopes youtube.upload, youtube and yt-analytics.readonly.
  • Channel data: the channel's own video list, titles, privacy status, view and like counts, and aggregated analytics (views, watch time, average view percentage) for the channel's own videos.
  • Uploads: the app sends the channel's own video files, thumbnails, titles, descriptions, tags and scheduling settings to YouTube.

The app does not access data about any other YouTube user, viewer, subscriber or commenter, and does not collect personal information from viewers. Videos are marked "made for kids" and the app does not read or manage comments.

How the data is used, stored and shared

  • Data is used only to publish the channel's own videos and to plan future episodes based on the channel's own performance.
  • The OAuth token and a small statistics file are stored locally on the channel owner's computer. Nothing is stored on a server operated by LumiTale Studio.
  • Aggregated statistics of the channel's own videos (titles, view counts, watch time) may be included in requests to the Anthropic Claude API, which helps plan new episode ideas. No personal data of any YouTube user is shared. YouTube data is not sold and is not shared with advertisers.
  • Stored YouTube API data is refreshed or deleted within 30 days.

Cookies

The app is a desktop command-line tool. It does not place, access or recognize cookies or similar technologies on any user's device or browser.

Revoking access and deleting data

Access can be revoked at any time on the Google security settings page. Deleting the local credentials and data folders removes all stored tokens and statistics. To request deletion or ask a question, contact us using the address below; we respond within 7 days.
